# Skill: API Integration

Use when integrating a REST/GraphQL endpoint.

## Process

1. Identify client and service conventions.
2. Define request/response models.
3. Implement client method.
4. Map data into domain if required.
5. Handle failures consistently.
6. Add repository/data-source wiring.
7. Connect to state management.
8. Test parsing and behavior.
9. Generate code if required.
