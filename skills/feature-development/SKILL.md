# Skill: Feature Development

Use when implementing a complete feature.

## Process

1. Read project instructions.
2. Run project discovery.
3. Find analogous feature.
4. Define acceptance criteria.
5. Implement using existing architecture.
6. Wire state management.
7. Wire navigation.
8. Add error/loading/empty states.
9. Add tests.
10. Run generators if needed.
11. Format/analyze/test.
12. Review diff.

## Quality

Prefer the smallest coherent change.
