# Skill: Flutter Project Discovery

Use this before substantial work in an unfamiliar Flutter repository.

## Detect

- SDK constraints
- packages
- architecture
- state management
- routing
- API layer
- persistence
- dependency injection
- code generation
- tests
- flavor/environment setup

## Output

Provide a concise project map and identify the closest existing implementation to copy.

## Rule

Do not redesign the project during discovery.
