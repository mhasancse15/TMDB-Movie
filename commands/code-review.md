# Command: code-review

Review for:

Architecture:
- correct dependency direction
- duplicated abstractions
- unnecessary coupling

Flutter:
- rebuilds
- widget size
- lifecycle/disposal
- accessibility

State:
- predictable state
- async/error handling
- duplicate state

Networking:
- error handling
- retries/timeouts
- secret logging

Testing:
- regression coverage
- brittle tests

Security:
- credentials
- unsafe logging
- untrusted input

Output findings by severity and explain concrete fixes.
