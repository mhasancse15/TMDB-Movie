# Command: create-feature

1. Analyze project architecture.
2. Find a similar existing feature.
3. Copy the project's pattern, not this kit's preferred pattern.
4. Add domain/data/presentation layers only if the project uses them.
5. Add models/entities/repository/provider as appropriate.
6. Add routing/UI.
7. Add tests.
8. Generate code if required.
9. Format, analyze, test.
