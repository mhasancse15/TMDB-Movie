# Command: analyze-project

Goal: understand an unfamiliar Flutter project before coding.

Steps:
1. Read pubspec.yaml.
2. Read project-level AI instructions.
3. Inspect lib/ and test/.
4. Identify architecture and feature boundaries.
5. Identify state management.
6. Identify routing.
7. Identify networking.
8. Identify persistence.
9. Identify code generation.
10. Identify testing conventions.
11. Report findings and risks.
12. Do not modify code unless requested.
